# 首批打印实现契约

依据 REQUIREMENTS §1.1、§4、§5 及实施前确定范围/布局/授权/适配/许可的要求，
本批先实现可供界面调用的系统打印适配，不新增业务实体或第三方打印依赖。

- 首个界面接入目标为审计列表**当前已加载分页**，不是所有筛选结果，也不是后台全量导出。
  审计继续只读，打印不改变查询或记录。
- 报告为纯文本：本地化标题、五列字段名、当前页记录；界面先展示将发送的完整文本。
  不解释 HTML、Markdown、脚本或外部资源，不执行 shell 或启动任意程序。
- 确认前须重新读取当前用户，核对姓名、角色及 `audit.export` 权限；查询/身份/页面实例变化使旧预览失效。
  原生适配只接收界面提供的已授权文本，不读取数据库或任意路径。
- 单份 UTF-8 文本不超过 1 MiB；拒绝空文本、无效编码和 NUL。
  原生按可打印区域换行和分页，不静默截断正文。取消系统对话框不提交打印作业。
- Windows 使用系统打印对话框及 GDI，Linux 使用 GTK PrintOperation/Pango/Cairo；
  沿用平台 SDK/GTK 依赖，无第三方打印包。打印机驱动和目标由用户在系统对话框选择。
- 方法通道为 `keel/desktop_files` 的 `printReport`，参数 `{title: String, content: String}`；
  成功提交返回 `printed`，用户取消返回 `cancelled`。打印机实际完成不属于该返回值承诺。
  错误返回稳定通道错误，不暴露正文、私人路径、驱动内部错误或打印机地址。
- 界面调用为单飞，原生对话框/提交期间纳入活动、页面关闭和可取消退出守卫；
  异步结束后复查 mounted/活动页/请求代次，避免迟到反馈作用于新页面。

当前源码已接审计当前页按钮（`lib/ui/pages/audit_page.dart`）及完整文本预览、
确认前重新读取身份/权限、查询与身份快照失效检查和单飞锁
（`lib/features/audit/ui/audit_print_actions.dart`）。
这些接线仍须正常生成/编译并运行回归，不能因方法通道或界面源码存在就关闭“打印”需求。
Windows/Linux 编译、真实取消/分页/Unicode/长行、空白页、驱动错误、busy 与退出均须目标平台验证。
